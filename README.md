# 🏆 LatihanJawara

Interactive Quiz & Practice Web Application for Primary & Secondary School Subjects.

Aplikasi web latihan soal interaktif (Bahasa, Matematika, Religi/Agama, Science, Social) dengan sistem skoring dan gamifikasi.

## 🛠️ Tech Stack & Language
- **Language**: JavaScript (ES6+), HTML5, CSS3
- **Database / Backend**: Firebase Realtime Database
- **Hosting**: Vercel / GitHub Pages

## 🚀 Features
- **Multi-Subject Quizzes**: Bahasa, Math, Religi, Science, Social.
- **Score Calculation & Leaderboard**: Real-time feedback & question sets.

## 🔐 Security & Configuration
- Configuration & API keys isolated via `public/firebase-config.js` (ignored in git).
